# PlayLizard
A simple gag that attaches an mp3 to your space bar. It's the "lizard" button from the movie Hoppers.

If you want to prank your friends, you'll need to either compile this on your own, or make sure they already have python installed on their machine. Does require deployment via USB stick. 

## Note:
Requires installLibs from Helpers found here: [Helpers](https://github.com/sircornelius22/Helpers.git)
